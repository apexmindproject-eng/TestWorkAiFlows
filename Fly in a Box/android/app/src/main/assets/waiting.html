This app is a window. The simulation itself (the whole FlyWire brain and the MuJoCo body) is a separate program that has to be running first.

To run it on this phone:

  1. Install Termux from F-Droid (not the Play Store).
  2. In Termux, once (10 to 20 minutes, about 3 GB):
    curl -sL "https://raw.githubusercontent.com/apexmindproject-eng/TestWorkAiFlows/claude/tanae-stuff-hhwfq6/Fly%20in%20a%20Box/phone/install.sh" | bash
    It asks for your GitHub user name and a token once.
  3. Then, every time:
    bash ~/fly.sh
    The brain takes about a minute to load. Leave Termux running and come back here.

Expect slow motion: one simulated second takes one to three minutes of compute on a phone.

On the computer: python flybox.py --live 8765, and check that the phone is on the same Wi-Fi and the firewall allows port 8765.
